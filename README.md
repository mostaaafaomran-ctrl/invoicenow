# Free invoice & quote maker, Arabic + English

Free invoice and quote maker for freelancers. Arabic and English, EGP/USD, print to PDF. No signup.

**Live:** https://mostaaafaomran-ctrl.github.io/invoicenow/

- Runs fully in the browser, nothing uploaded, no signup
- Plain HTML/CSS/JS, no build step, no dependencies
- Arabic and English

## Run locally
Open `index.html` in a browser.

## Logic tests
`core.js` works in Node: `node -e "console.log(Object.keys(require('./core.js')))"`
